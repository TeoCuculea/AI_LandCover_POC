# Exerciții

Scripturi scurte pentru înțelegerea codului. Fiecare are instrucțiunile la început și întrebări la sfârșit. Se rulează din rădăcina proiectului.

## Ziua 1: bucla de antrenare și ResNet18

| Exercițiu | Tip | Comandă |
|---|---|---|
| 1. Supraînvață un singur lot | scrii tu bucla | `python -m exercises.ziua_01_ex1_un_singur_lot` |
| 2. Ce se întâmplă fără `model.eval()` | prezici, apoi rulezi | `python -m exercises.ziua_01_ex2_train_vs_eval` |
| 3. Forma tensorului prin rețea | completezi predicțiile | `python -m exercises.ziua_01_ex3_forme` |
| 4. Trei formule scrise de tine | scrii funcțiile, verificările sunt incluse | `python -m exercises.ziua_01_ex4_de_mana` |

Ordinea recomandată: 4, 3, 1, 2. Exercițiul 2 are nevoie de modelul antrenat din `results/runs/disertatie_final_01/models/`, care există doar local.
